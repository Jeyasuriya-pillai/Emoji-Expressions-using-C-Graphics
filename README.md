# 😀 Emoji Expressions Animation using C Graphics

This project demonstrates multiple facial expressions using C programming and the graphics.h (BGI) library in Turbo C++.

## 🎭 Expressions Included
- Crying face 😢
- Happy smile 😊
- Normal face 🙂
- Straight face 😐
- Evil face 😈

## 🛠️ Technologies Used
- C Programming
- graphics.h (BGI)
- Turbo C++

## 📌 Features
- Multiple facial expressions using shapes (circle, ellipse, line, arc)
- Step-by-step animation using screen clearing
- Creative use of graphics functions

## ▶️ How to Run
1. Open Turbo C++
2. Load the file `emoji.c`
3. Set BGI path
